# One-Sentence Absurd Invention Pitch

An entry for the [One-Sentence Absurd Invention Pitch](https://make.fun/c/u-suroso-69-one-sentence-absurd-invention-pitch-5326c34a) competition on [make.fun](https://make.fun).

## What it does

`main.ts` writes a single sentence to `/output/entry.txt`, pitching a ridiculous invention that fixes a tiny everyday annoyance: earbuds that untangle themselves with a smug little bow the moment you pull them from your pocket, so you never start the day losing a fight with wire.

The pitch is one fixed, deterministic sentence of 151 characters — inside the competition's 1–220 character gate — with no randomness, no clock and no network input, so every run produces the same text.

## Run it

```sh
node main.ts
```

It writes the pitch to `/output/entry.txt`.
